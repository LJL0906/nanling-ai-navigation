# 管理员登录与审核说明

## 入口与账号配置

点击前台「设置」会跳转到 `/admin/login/`。已登录时自动进入后台；直接打开管理页面且未登录时，先登录再返回原页面。

在部署环境或本地 `.env` 中设置以下服务端变量，然后重启服务：

```dotenv
ADMIN_USERNAME=你的管理员账号
ADMIN_PASSWORD=你自行设置的高强度唯一密码
```

不提供默认账号密码；不要使用 `PUBLIC_` 前缀，不要提交真实凭据。原 `ADMIN_TOKEN` 仍可用于 CLI 的 Bearer 接口认证，但不再作为网页登录密码。

## 独立后台布局

后台使用独立 `AdminLayout`，不再嵌入前台导航页面，不加载前台侧栏、顶部搜索、投稿弹窗或主题脚本。登录页面独立展示；登录后的标准布局包含深色侧边管理菜单、顶部账号与退出入口、面包屑、浅色内容工作区。窄屏下管理菜单切换为抽屉。管理内容页仅保留查询条件、数据表格、分页和操作按钮；去除大标题、介绍、流程说明及宣传页脚。必要的错误反馈、空数据状态、字段标签和删除确认继续保留。

- `/admin/`：直接跳转导航卡片管理，不再显示概览大屏。
- `/admin/sites/`：独立导航卡片管理页面，支持新增、编辑、删除、搜索、分类筛选与分页。
- `/admin/categories/`：分类管理，支持新增、编辑、删除、排序和关联站点统计。
- 菜单维护、提交审批各自拥有独立页面，切换不依赖前台界面。

## 管理功能

- `/admin/`：管理入口，跳转 `/admin/sites/`。
- `/admin/sites/`：导航卡片管理，支持新增、编辑、删除、关键词查询、分类筛选和分页；可维护名称、网址、简介、标签、所属分类及排序。管理员新增保存后直接发布，无需再次审批。
- `/admin/categories/`：维护分类名称、路径标识、颜色、Lucide 图标及排序；显示关联站点数。
- `/admin/menus/`：沿用菜单编辑工作台，支持新增、编辑、删除、排序、显隐与整份保存，保存使用版本冲突校验。MySQL 模式才支持写入；seed 模式只读。
- `/admin/reviews/`：查看用户提交的待审核记录，审批通过或拒绝并记录审核信息，按状态查询审核历史。

**审批通过直接发布导航卡片。** 审核状态与站点发布在同一 MySQL 事务中提交，任一步失败则回滚，记录仍可重试；前台刷新后读取最新数据。已有分类直接归类，自定义分类会复用同名分类或新建分类；重复站点地址返回冲突，不覆盖现有卡片。审核备注保持私有，审核通过不等于已完成网站在线检测。

正式提交和审核记录保存在 MySQL 的 `nav_submissions` 表，发布写入 `nav_sites`；需先运行数据库迁移建立所需表。历史文件记录须通过迁移工具导入后才会出现在正式后台，不会因升级自动审核或发布。现有提交接口的 OSS 配置不变。

## 内容增删改规则

- 内容接口：`GET /api/admin/content?kind=sites|categories`；新增 `POST`、编辑 `PATCH`、删除 `DELETE` 使用 `/api/admin/content`，模块 `kind` 放在 JSON 请求体中。所有接口均需管理员认证；Cookie 写请求必须同源。
- 新增请求为 `{kind,item}`；编辑为 `{kind,id,revision,item}`；删除为 `{kind,id,revision}`。ID 由服务器生成，版本来自最近一次读取。过期版本返回 409，不覆盖其他管理员或窗口的修改。
- 站点和分类写入只支持 MySQL。种子模式显示只读并在服务端拒绝写入，不修改种子 JSON。新增保存即生效，发布成功后本进程清除导航缓存；其他进程最多延迟 30 秒，前台需重新加载。
- 站点 URL 必须是不含凭据的 HTTP(S) 地址；拒绝已有主地址或备用地址的重复录入。编辑保留原始来源、别名和图标等未开放字段；更改 URL 会将验证状态重置为未验证。
- 已有 slug 不允许改动。移动站点到其他分类会改变详情链接；原有精选来源链接继续按适配规则跳转，但不保证所有旧地址均有重定向。
- 删除站点不可恢复；数据库外键会同步清除该站点关联的用户收藏和最近访问记录。审核历史及其已发布站点编号保留，删除卡片不会改写历史审批结论。
- 分类存在关联站点、菜单或待审提交时禁止删除，需先移动/删除站点、调整菜单或处理待审记录。不自动级联删除整类内容；不允许删除最后一个站点或分类。
- 分类名称、图标和颜色用于前台分类展示；菜单的显示文案与排序为独立配置，需在菜单管理中维护。新分类可在分类目录访问，要加入侧栏须另建分类菜单。
- 审核记录属于审计记录：保留待审、通过、拒绝查询与审批；不提供修改已审核结论、伪造记录或直接删除历史的功能。已发布内容的修正和删除在导航卡片模块完成。
- 所有写入采用事务；站点维护与审核发布共享数据库命名锁。分类维护同时与菜单保存串行，防止关联检查后被并发写入绕过。页面有提交防重、删除确认和未保存表单提醒。

## 登录与安全边界

- 登录状态保存在服务端内存，浏览器只保存随机会话 Cookie，具有 HttpOnly、SameSite=Strict；HTTPS 请求还设置 Secure。
- 会话有效期为 8 小时；退出立即撤销，修改账号密码或重启服务后需重新登录。
- 所有后台页面均受登录保护；管理 API 单独鉴权，不依赖隐藏按钮。
- Cookie 登录的写操作与登录/退出均校验同源 Origin；公网部署应使用 HTTPS，代理需正确传递外部请求地址。
- 登录采用单进程全局失败限额（15 分钟内最多 10 次），不会信任客户端伪造的转发地址。
- 当前为单管理员、单进程会话方案，不提供多用户角色管理。多实例部署前需要共享会话与限流存储。
- 离开菜单页面仍会丢失未保存草稿，但不会退出登录。使用完毕请主动退出，尤其在共享电脑上。

## 验证

```sh
npm test
npm run typecheck
npm run build
node scripts/验收管理员入口.mjs
npm run test:build
```

认证、审核测试使用临时数据，不修改真实账户配置或线上记录。构建验收使用随机临时凭据与 seed 数据源验证登录、页面保护和退出撤销。
