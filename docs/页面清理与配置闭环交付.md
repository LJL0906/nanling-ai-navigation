# 页面清理与配置闭环交付

日期：2026-09-07。

## 交付结果

1. 删除 `/articles/`、`/quick-search/` 两个未实现页面及独占的 ComingSoon 组件；旧地址返回统一404，不重定向到无关首页，不再保留空壳。
2. `/tags/` 使用 `tags/sourceCategories` 动态细分；展示真实标签及站点数量，点击 `?sub=` 链接进入分类服务端筛选分页，不再冒充标签的站点名称列表。
3. 后台新增 `site-UUID`、审批 `submitted-UUID`、原有 `site_...` 共用合法ID契约，搜索、个人资料目录、收藏和历史均接受；保留ID原值，不修改数据库主键。
4. 新增 `/admin/settings/` 全站配置，连接 `/api/admin/settings` 和 MySQL `nav_settings`，前台逐请求读取。同请求嵌套组件共享懒加载Promise，跨请求不保留旧配置快照。
5. 站点名称、标语、首页标题/副标题、SEO默认描述/关键词、正式站点域名以及首页每批数量均生效。canonical、OG、JSON-LD、sitemap、侧栏/Logo替代文本及页脚接入配置；管理系统自身品牌不属于前台站点配置。
6. 首页首次渲染与标签切换使用配置数量，加载更多为两倍；种子默认18/36，配置允许1–48。`/settings/` 原后台转接语义不变。
7. 解决异步嵌套渲染后个人页和分类筛选页HTTP索引头可能缺失的问题；路由层确保这些页面noindex，与页面meta一致。

## 配置接口

- `GET /api/admin/settings`：`{ data: { site, homeSectionPageSize, revision, writable } }`。
- `PUT /api/admin/settings`：请求 `{ site, homeSectionPageSize, revision }`，返回保存后的同结构快照。
- `HEAD` 支持；其他方法返回405。
- 沿用管理员Cookie或Bearer鉴权；Cookie写入必须同源Origin。跨站请求拒绝。
- JSON上限32 KiB，严格白名单，字段类型/非空/长度限制，URL仅HTTP(S) origin，不允许账号、路径、query或hash。
- 版本不一致409且不覆盖；事务与命名锁保护两键原子保存和首次保存并发；失败回滚。
- 前端加载、保存期间禁用操作；冲突/错误保留草稿；重载前确认；登录失效提供恢复入口。

### 配置数据边界

`site`字段仅：url、name、slogan、heroTitle、heroSubtitle、description、keywords。

只管理`site`与`homeSectionPageSize`两个键，不复活已删除的hotSearches等历史行为，不从currentUser快照伪造账号身份，精选仍由nav_menus维护。数据库读取兼容site旧快照额外字段；保存使用当前7字段，不恢复不可靠的lastmod日期。

- seed模式：源码默认、只读，写入503。
- MySQL模式：缺键使用源码默认；数据库异常或损坏配置明确报错，不静默回退。
- 使用既有nav_settings表，无新增表迁移。尚未初始化该表的环境需按原菜单初始化说明建表。
- 保存后新请求立即生效；已经打开的页面需要重新加载。
- 主题、搜索历史、用户侧栏排序继续采用原本的本地偏好，不扩大为账号同步需求。

## 验证

- 全量测试、类型检查、生产构建、构建产物和SEO验收结果见reports下“闭环改造”日志。
- ID回归覆盖完整种子目录混入两种新增ID、搜索分页、个人目录、API响应和服务端校验。
- 配置后端模拟事务测试覆盖并发冲突、第二键写入失败和提交失败回滚，不将内存测试宣称为真实数据库并发测试。
- 真实MySQL联调18项通过：鉴权、Cookie同源、跨站拒绝、参数校验、错误版本、当前同值保存、接口回读、数据库读取、首页品牌/数量、sitemap域名、占位404及标签目标。
- 实库联调只保存原业务值；没有变更站点、用户、菜单，也没有向公开站点写入临时测试品牌。实库故障回滚和并发写压力未测试。
- 后台交互有模拟DOM测试；未执行真实浏览器逐项点击，也未执行第三方外链可用性检测。
