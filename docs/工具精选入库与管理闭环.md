# 工具精选入库与管理闭环

## 数据源与展示

- 继续使用已有 `nav_menus`，无需新表、迁移或再次导入。没有执行数据库读写验收、迁移或同步脚本。
- `/discover/` 每次请求调用 `getPublicMenus()`，只展示启用的 `topbar` 根分组及其启用的 `resource` 子项；普通链接不计入精选资源。
- 顶栏本来就读取同一公开菜单接口，因此后台保存成功后，刷新顶栏所在页面和 `/discover/` 都会读取新内容。已打开页面不会自动推送更新。
- 名称与访问链接以行上的 `label`、`href` 为准，不使用旧 payload 内复制的 `name`、`url`。资源 ID 使用菜单行 ID；排序按 `sortOrder` 和行 ID。
- 保留原有 `payload.groupId` 的合法锚点，使已导入的“查看全部”链接继续有效；新分组缺少该字段时使用菜单行 ID 生成稳定锚点。
- 描述、用途、来源 URL、来源标题、核对日期读取 payload。缺失资料会明确显示未填写，不拿访问地址充当来源、不虚构核对日期。
- 空目录和空分组有明确空态。数据库读取或数据校验出错时向上抛错，不捕获后导入静态精选。页面声明服务端渲染及 `Cache-Control: no-store`。
- 未配置 MySQL 时仍遵循全站原有只读种子存储模式；这是明确的存储配置，不是数据库出错后的降级。

## 后台操作

在现有 `/admin/menus/` 完成管理，不另建页面、不新增导航入口。

1. 点击“新增精选分组”，填写名称、分组描述、图标和排序，勾选启用。
2. 选中分组后点击“新增精选资源”，会优先归入该组；没有分组时明确提示先新增分组。
3. 资源可填写描述 `description`、用途 `useCase`、来源链接 `sourceUrl`、来源标题 `sourceTitle`、核对日期 `checkedAt`。修改父级可移动资源。
4. 新项默认隐藏；资源和父级分组都启用才公开。点击“应用到本页草稿”尚未提交服务器，必须点击“保存全部”。
5. 保存成功后刷新前台及目录验收。隐藏父组会隐藏其所有资源；删除父组有确认提示，并从草稿级联删除子项，保存成功才生效。
6. 清空可视化字段会删除对应 payload 属性。高级 JSON 的其他键原样保留；同一轮编辑中，实际改动的可视化字段优先于高级 JSON，未动的字段不覆盖 JSON。应用后回填合并结果。
7. 继续沿用鉴权、版本冲突保护、一次提交、失败草稿保留和重试。409 后必须重新加载，不能强行覆盖其他管理员版本。

## 安全与边界

- 访问链接支持站内绝对路径及完整 HTTP(S)；来源仅支持完整 HTTP(S)。拒绝脚本协议、协议相对地址、凭据 URL、反斜线、空白、控制字符及编码控制字符。
- 前端与服务端共用纯校验规则；服务端还校验整份菜单结构及 payload。来源标题最多 255 字符、来源 URL 最多 2048 字符、描述及用途最多 4000 字符。
- 核对日期必须为真实的 `YYYY-MM-DD` 日历日期（包括闰年判断），不自动填写或联网核验。
- 页面以 Astro 文本插值输出，并为新窗口链接设置 `noopener noreferrer`；不使用原始 HTML 渲染管理员字段。
- URL 校验仅保证链接语法及协议边界，不证明目标网站安全、持续可达或来源真实；没有新增服务端抓取功能。
- 整份菜单原有的至少 1 条限制不变；可以清空所有精选分组与资源并保留其他导航。不要清空整张菜单表。

直接运行，不加载 `.env`、不连接数据库：

```powershell
node --test scripts/精选菜单后台.test.mjs scripts/精选菜单闭环.test.mjs
```
