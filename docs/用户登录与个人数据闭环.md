# 用户登录与个人数据闭环

## 使用方式

- 顶部“登录 / 注册”打开居中弹窗，只需用户名和密码；用户名 3–32 位字母、数字或下划线，统一小写；密码 10–128 个字符。
- 未登录点击收藏、我的收藏或最近访问，会打开登录弹窗。浏览站点不强制登录，但未登录不会新增最近访问记录。
- 登录后收藏、取消收藏、最近访问、移除与清空都通过服务端接口写 MySQL。相同账号在不同设备登录后读取相同记录。
- 提交站点也必须登录，未登录通过登录弹窗完成认证；提交归属及审核通知绑定当前账号。原有内容校验、限流与审核仍保留。
- 普通用户与管理员是两套独立身份，注册普通用户不会获得管理权限。
- `/login/`、`/register/` 提供直接访问页面，正常导航使用居中弹窗。

## 数据库与部署

先准备已有站点表和 MySQL 配置，然后执行：

```powershell
npm run db:migrate-accounts -- --apply
npm run build
npm start
```

新表：

| 表 | 内容 |
| --- | --- |
| `nav_users` | 用户 ID、唯一用户名、密码哈希、创建时间 |
| `nav_user_sessions` | 会话 token 的 SHA-256 摘要、用户 ID、过期时间 |
| `nav_user_records` | 按用户/类型/站点唯一保存收藏和访问记录 |

迁移只执行 `CREATE TABLE IF NOT EXISTS`，不覆盖已有数据；MySQL DDL 可能部分成功，修复后可重复执行。请求过程中不自动建表。`NAV_STORAGE=seed` 不支持账号写入，不伪装为本地保存。

## 接口

所有个人数据 API 都通过 HttpOnly Cookie 获取当前用户，**不接受客户端指定其他用户 ID**。

- `POST /api/account/register`：`{username,password}`，注册且登录。
- `POST /api/account/session`：`{username,password}`，登录。
- `GET /api/account/session`：返回当前用户或 null。
- `DELETE /api/account/session`：退出当前会话。
- `GET /api/personal`：返回 `{data:{favorites,history}}`。
- `POST /api/personal`：接受以下操作并返回完整个人记录快照：
  - `{action:'favorite',siteId,selected}`：明确设置收藏状态，重复请求不会反复切换。
  - `{action:'visit',siteId,visitType:'detail'|'external'}`：更新最近访问。
  - `{action:'remove',kind:'favorites'|'history',siteId}`：移除单条。
  - `{action:'clear',kind:'favorites'|'history'}`：清空对应列表。
  - `{action:'import',favorites,history}`：迁移旧浏览器记录，按站点和时间合并。

最近访问最多保留 100 个站点。写入事务锁定当前账号行，保证多设备写入时的列表上限与合并一致性。站点不存在时普通写入返回 404；迁移跳过已下架站点。所有操作限定当前用户。

## 本地旧数据迁移

登录后读取原有 `nav:favorites:v1` 和 `nav:history:v1`，经服务端确认导入成功才删除旧键。失败保留原数据并提示，不报告假成功。旧记录归属于首次迁移时登录的账号；共用浏览器应确认当前账号后使用。未登录不再生成新的本地收藏或访问记录。

## 安全与边界

- 密码使用随机盐和异步 scrypt 哈希，不保存明文；限制昂贵哈希并发。
- 会话 token 随机生成，数据库只存摘要；Cookie 为 HttpOnly、SameSite=Lax，HTTPS 下启用 Secure，有效期 7 天。服务重启不丢失有效数据库会话。
- 登录、注册、退出、个人写入要求同源；JSON 请求按实际请求流限制大小；响应使用 no-store。
- 登录注册按可信客户端来源及用户名分别进行进程内限流，不信任 X-Forwarded-For；来源不可得时保守共用未知来源额度，同 NAT/代理可能共享额度。多实例生产环境仍需可信网关或共享限流服务；进程重启会清空限流预算。全局哈希资源使用短时并发限制，不使用会被单一来源长期耗尽的全站登录总额度。
- 登录账号没有邮箱或手机号，因此本次不包含找回密码、验证码、邮箱验证、多因素认证和账号注销。
- 过期会话不可用于认证；可由后续运维任务定期删除过期会话行。
- 清浏览器 Cookie 会退出登录，但数据库个人记录不丢失，重新登录即可恢复。
- 站点提交接口要求普通用户身份；管理员审核接口继续采用独立管理鉴权，普通用户登录不提供管理权限。
