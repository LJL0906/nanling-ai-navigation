# 动态分类细分说明

## 数据与展示

- 首页和分类页共用 `src/lib/category-facets.ts`，从当前导航快照中每个站点的 `tags`、`sourceCategories` 派生细分，不依赖站点 slug 白名单或固定正则规则。
- 现有后台编辑站点标签即可更新细分；快照刷新后新增站点自动加入同名标签。来源分类仍参与多重归属，不推测站点名称或描述的语义。
- 标签进行 NFKC、空白和大小写归一化；来源层级按 `|`、`｜`、`>`、`＞` 拆分，去除一级分类名称与重复标签。不限制细分数量，不截断记录。
- “全部”始终是默认项，覆盖全部站点；缺少有效标签的记录进入“未细分”。未知或旧的 `sub` 参数安全回到全部。
- 标签作为文本渲染，URL 参数和首页标签 DOM ID 使用编码；不执行标签内容。

## 分页

- 分类页服务端先筛选完整分类，再按 48 条分页。每个细分、全部均有完整分页，切换细分回到第一页，分页链接保留 `sub` 参数。
- 过期细分页码收敛到该筛选最后一页。结构化列表只包含实际展示的当前页，canonical 包含有效细分参数。
- 浏览器脚本不再重新过滤卡片或隐藏分页，无 JavaScript 同样可以切换和翻页。
- 首页沿用首屏 18 条、每次追加 36 条的加载机制，所有动态细分及全部项均保留完整索引。

## 修改边界与集成提醒

- 不新增后台、不写库、不访问远程；不修改内容 CRUD、管理页、适配器、排序、稳定 ID 或 redirect。
- `menu-seed.ts` 仍导入已删除的 `CATEGORY_TABS` / `HOME_TAB_RULES`，需由主 Agent 移除旧导入及规则快照序列化，或替换为动态细分策略说明。此文件不在本任务修改范围内；不要恢复固定规则来掩盖依赖。
- 只更新已有分类默认标签和首页分区测试；其他 Agent 测试不修改。
