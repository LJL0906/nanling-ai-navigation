# 站点图标补充说明

## 用途

`补充站点图标.py` 使用 Python 3.10+ 标准库批量下载导航站点缺少的图标，无需安装第三方 Python 包。

- 保留当前 Iconify 品牌图标和旧精选品牌图标，不覆盖已有的有效本地缓存。
- 优先尝试原始图片地址，再请求站点的 `/favicon.ico`，最后读取页面声明的 favicon / Apple touch icon。
- 图片保存到 `public/site-icons/`，文件名使用内容 SHA-256，相同图片只保存一份。
- `src/data/站点图标.json` 保存站点 ID 到本地图片路径的映射；原始 `导航数据.json`、站点 URL、分类和验证状态不变。
- 前端只使用白名单内的本地图片地址，不直接加载原始外站图片。获取失败时继续使用首字兜底，不用假品牌图标冒充成功。

## 执行

在项目根目录运行：

```powershell
# 只统计，不联网、不写文件
python -B scripts/补充站点图标.py --dry-run

# 先补前 20 条，检查结果
python -B scripts/补充站点图标.py --limit 20

# 全量补充（默认 12 并发，单次连接/读取超时 5 秒）
python -B scripts/补充站点图标.py

# 网络不稳定时降低并发、增加超时；有效缓存会自动跳过
python -B scripts/补充站点图标.py --workers 8 --timeout 12

# 脚本的离线单元测试（不请求外网）
python -B scripts/补充站点图标_test.py -v
```

脚本通过自身位置定位项目，因此不依赖命令执行时的当前目录。`--limit` 只计算待补充的记录，不包含已有图标和有效缓存；重复运行会修复图片丢失或内容损坏的缓存，也会重试上次失败的站点。

每约 25 条处理结果原子保存一次映射，完成后生成 `reports/站点图标补充报告.json`，记录本次成功、失败、错误原因、图标来源和仍未补充的数量。报告覆盖上次运行结果，映射和成功图片则持续保留。部分站点失败不会中止整个批次，也不会导致非零退出码；应根据报告里的 `remaining` / `counts.failed` 判断是否还有缺失。输入错误等任务级失败返回 1，手动中断返回 130。

任务运行时创建 `src/data/站点图标.json.lock` 防止同时改写。异常断电等情况可能留下锁文件，仅在确认没有运行中的补图进程后才手动移除。强制结束进程前尚未进入映射检查点的图片，可能需要下次重新抓取。

Windows 终端显示中文乱码时可先执行 `$env:PYTHONIOENCODING='utf-8'`。`-B` 用于避免生成 `__pycache__`，不影响脚本功能。

## 安全与限制

- 下载 PNG、ICO、JPEG、GIF、WebP，检查文件结构、单张不超过 2 MiB；PNG/GIF 限制尺寸不超过 4096 像素。此检查不等同于完整图像解码或安全审计。
- 不保存远程 SVG，避免将未经清洗的主动内容直接放到本站域名下；只提供 SVG 的站点可能仍然缺失。
- 仅请求公开 HTTP(S) 地址，拒绝带账号密码的 URL、本机、内网和保留地址，并检查每次重定向。保留 TLS 证书校验，不携带用户登录 Cookie，不绕过验证码或访问控制。
- 超时是单次连接/读取超时，不是整个站点任务的总时限；DNS 解析受操作系统控制。
- DNS 失效、403/404、证书错误、反爬、超时及非图片响应都可能导致无法获取。脚本不能保证所有站点都有可访问的真实品牌图标。
- 图标下载成功不代表站点已通过可用性、安全或授权审核。第三方品牌图片仍受各自条款约束。

## 页面与部署

补充完成后，开发服务器会读取更新后的映射；生产环境需要重新构建并部署，不能只运行脚本而不发布产物：

```powershell
npm run validate:data
npm test
npm run typecheck
npm run build
npm run test:build
```

需要一并保留 `src/data/站点图标.json` 与 `public/site-icons/` 的全部引用图片；不要只提交映射而遗漏图片。图标映射在代码适配层应用，种子数据和 MySQL 仓储共用该适配流程，无需写数据库或重新导入站点。生产构建将图片复制到 `dist/client/site-icons/`。

`--data`、`--legacy`、`--manifest`、`--icons-dir`、`--report` 可指定测试输入输出。页面默认只读取上述项目路径；自定义输出不会自动改变前端配置。

## 本次运行结果（2026-09-07）

- 总计 2400 条站点，保留 28 条原有品牌图标，累计补充 1836 条本地图标；带图标共 1864 条，剩余 536 条保持首字兜底。
- 实际下载 1575 个去重图片文件，约 29.86 MiB；成功映射对应的图片均存在，内容 SHA-256 与文件名一致。
- 全量抓取后，使用 12 并发、10 秒超时重试失败项，额外成功 36 条。报告记录的是最近这轮重试，因此 `downloaded: 36` 并非累计总数；累计数以映射为准。
- Python 离线测试 18 项、当前项目 Node 测试 269 项通过；数据校验、类型检查、生产构建及构建产物检查通过。
- 生产启动抽查：首页输出 229 个本地图像元素；搜索及个人索引均含 1836 条本地图标；PNG、ICO、JPEG、WebP、GIF 五种格式抽样请求全部 HTTP 200，响应内容与磁盘图片一致。
- 只完成本地文件和构建验证，未执行线上部署或数据库写入。
