# 收藏与访问记录前端功能

## 已实现

- 首页、分类、搜索、站点详情和同类推荐提供独立收藏星星；点击星星不会打开链接。
- 收藏状态在当前页面所有卡片、动态加载卡片、刷新及同源浏览器标签页间同步。
- `/favorites/` 展示收藏，支持关键词筛选、取消收藏、逐条移除、清空确认和每批 48 条加载更多。
- `/history/` 展示最近访问，浏览站点详情或点击官网入口时记录；同一站点重复访问置顶，最多保留 100 个不同站点。
- 历史页支持筛选、逐条移除、清空确认、加载更多；原搜索关键词历史是独立功能，不会互相清空。
- 已下架站点保留可删除的占位记录，不误跳到其他站点。
- 存储不可用、写入超限、索引加载失败都有提示；写入失败不显示成功。

## 数据边界

收藏与访问记录**只保存在当前浏览器的 localStorage**，未上传至服务器，没有登录、账号同步或跨设备同步。
站点详情文本通过本站只读 `/personal-sites.json` 索引取得；该接口不保存个人行为数据。
不同域名、协议或端口属于不同浏览器存储空间。清理浏览器站点数据会清除本地记录。

稳定 ID 为统一站点库的 `site.id`，不使用名称或 URL 作为个人数据主键。

| 键 | 数据 |
| --- | --- |
| `nav:favorites:v1` | `[{ siteId, updatedAt }]` |
| `nav:history:v1` | `[{ siteId, updatedAt, visitType: 'detail' 或 'external' }]` |

访问记录表示本站详情浏览或官网入口点击，不宣称外站已经成功加载；浏览器“右键菜单 → 在新标签页打开外站”无法可靠捕获，不保证记录。正常左键、键盘激活及鼠标中键已接入事件处理。

## 代码入口与后续接口接入

- `src/lib/personal-store.ts`：独立数据仓库，集中处理读取、收藏切换、访问记录、移除、清空与校验，不依赖 DOM。
- `src/scripts/personal.ts`：星星和访问事件、状态同步、操作提示。
- `src/scripts/personal-page.ts`：个人列表渲染、筛选和列表操作。
- `src/components/ui/FavoriteButton.astro`：共用星星按钮。
- `src/pages/personal-sites.json.ts`：关联当前站点资料的只读索引，复用现有 `getNavigation()`。

后端阶段可保留站点 ID 和记录结构，为仓库增加异步 API 实现，再将 UI 的仓库调用调整为等待请求完成。届时需要明确登录身份、离线策略、本地记录迁移授权、服务端去重及并发合并规则；本次不假设这些接口已存在。

## 验证

运行 `node --test scripts/收藏访问记录.test.mjs`，覆盖初始空数据、收藏切换、刷新保留、历史去重和上限、移除/清空隔离、损坏数据、存储失败、非法 ID 和多实例存储更新。
